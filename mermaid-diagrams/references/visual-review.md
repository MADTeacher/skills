# Visual Review

Используй этот файл после успешного PNG-рендера. Проверка считается
выполненной только когда языковая модель напрямую видит последний PNG.

## Procedure

1. Открой PNG прямым инструментом просмотра изображения или передай локальный
   PNG как изображение в контекст модели.
2. Сравни видимый результат с пользовательским брифом и Mermaid-исходником.
3. Дай verdict `PASS` или `FAIL`.
4. Для `FAIL` перечисли конкретные видимые дефекты и исправь Mermaid-исходник.
5. Повтори `source -> PNG -> visual review` после правки.

## PASS Criteria

- Смысл соответствует брифу: нужные сущности, связи, направление и исключения
  присутствуют.
- Чтение понятно без устного сопровождения: есть очевидный старт, направление
  движения и финальные состояния.
- Текст читается при обычном масштабе: нет обрезки, наложения, слишком мелких
  подписей или длинных неразбитых строк.
- Стрелки и связи различимы: подписи ребер не сливаются с узлами, пересечения
  не создают ложный смысл.
- Группы и зоны помогают чтению, а не прячут связи.
- Контраст достаточный для светлого и печатного просмотра, если пользователь не
  задал другое.
- PNG не пустой, не обрезан по краям и не содержит renderer error text.

## Common FAIL Signals

- renderer показывает ошибку синтаксиса вместо диаграммы;
- один или несколько узлов обрезаны краем PNG;
- длинные labels вылезают за узлы или перекрывают стрелки;
- стрелка проходит через чужой узел так, что связь становится неоднозначной;
- группы `subgraph` слиплись или создают ложную вложенность;
- исключение или обратная связь выглядит как основной путь;
- диаграмма слишком плотная и требует разделения на несколько PNG.

## Review Note Format

Используй короткую внутреннюю заметку перед финальной сдачей:

```text
visual gate: PASS
checked: content, readability, arrows, clipping, overlap, contrast
notes: <1-2 concrete observations>
```

Для неготовой диаграммы:

```text
visual gate: FAIL
blocking issues: <visible defects>
next fix: <specific Mermaid source change>
```
