# Skills

Репозиторий с персональными навыками для Codex и других агентных сценариев:
от TDD и диагностики багов до генерации PRD, декомпозиции задач, дизайна,
диаграмм и презентаций.

Каждый навык — это отдельная папка с `SKILL.md`. Внутри могут быть
дополнительные `references/`, `scripts/`, `assets/`, `evals/`, тестовые
промпты и README конкретного навыка. Корневой README служит каталогом и
быстрым ориентиром.

## Как использовать

1. Подключите нужные папки навыков в окружение агента или храните этот
   репозиторий как локальную директорию skills.
2. Вызывайте навык по названию или формулируйте задачу так, чтобы она совпадала
   с `description` в `SKILL.md`.
3. Для сложных навыков сначала читайте верхний уровень `SKILL.md`, а затем
   открывайте только те материалы из `references/` или `scripts/`, которые
   нужны для текущей задачи.

## Структура навыка

- `SKILL.md` — главный операционный контракт: когда срабатывает навык и как
  агент должен действовать.
- `references/` — подробные инструкции, чеклисты, рубрики и фреймворки,
  которые не нужно держать в основном файле.
- `scripts/` — проверяемые действия: валидация, экспорт, рендер, smoke tests
  или вспомогательные CLI-инструменты.
- `assets/` — шаблоны, изображения и другие переиспользуемые материалы.
- `evals/` — сценарии проверки качества навыка, если для него нужен отдельный
  оценочный контур.

## Поддержка каталога

При добавлении нового навыка:

1. создайте папку с понятным kebab-case именем;
2. добавьте `SKILL.md` с frontmatter `name`, `description`, `metadata`;
3. вынесите длинные материалы в `references/`, а проверяемые операции — в
   `scripts/`;
4. добавьте строку в таблицу выше;
5. если навык сложный или рискованный, добавьте eval/smoke-проверки и коротко
   опишите их в README навыка.
